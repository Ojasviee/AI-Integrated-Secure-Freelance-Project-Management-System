# AI-Integrated Secure Freelance System

## Overview
A full-stack web application that helps clients post freelance projects and automatically analyzes project risk using an AI-based fraud detection engine.

## Features

- User Registration & Login
- JWT Authentication
- Project Creation
- AI Risk Detection
- Trust Score Calculation
- Security Dashboard
- AI Insights Dashboard
- Fraud Alerts
- React Frontend
- Flask Backend
- SQLite Database

## Tech Stack

### Frontend
- React.js
- Axios
- React Router
- Recharts

### Backend
- Flask
- Flask-JWT-Extended
- SQLAlchemy
- SQLite
